# dawnstar-cme-tracker

Side Project for the Dawnstar Space Weather 3D CME (coronal mass ejections) Tracker.

## Status

Dawnstar is currently in early development.

## Data

CME data is provided by NASA's DONKI database.

## Tech Stack

* React
* JavaScript
* React Three Fiber
* Three.js

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will be available at `http://localhost:3000`.
